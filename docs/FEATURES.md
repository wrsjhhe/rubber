# 功能需求

本文描述目标，实际状态只维护在 [PROGRESS.md](PROGRESS.md)。编号保持稳定，供开发和审核共同引用。

## 应用范围

提供独立 C++ Vulkan 渲染库，用于仿真资产验证器、仿真测试系统和视觉传感器图像生成。支持无窗口使用；GLFW、ImGui 和示例资产不是核心库必要依赖。优先建立扩展框架，再增加传感器模型和真实感功能。

| 编号 | 功能 | 验收条件 |
|---|---|---|
| F01 | 场景与几何 | 父子变换、稳定 ID、快照隔离；Box/Sphere/Cylinder/Cone/Capsule/Convex/TriangleMesh 正确绘制；删除父节点删除子树 |
| F02 | 资产与共享 | 静态不透明 glTF/GLB、核心 PBR 贴图；同资产跨相机不重复上传；版本更新不污染旧快照 |
| F03 | 延迟 PBR | 底色/法线/金属粗糙度纹理、方向光、点光、CSM；色彩空间正确，G-buffer 可访问 |
| F04 | TAA 与历史 | 静止/运动相机回归通过；跳转、资产及效果变化使历史失效；抗锯齿不改变几何真值 |
| F05 | 按需输出 | 八种现有 Channel 可选择 CPU/GPU 交付；缺失通道显式报错；几何请求不执行光照/TAA |
| F06 | 多相机与保活 | 同快照两相机结果正确；旧结果在后续提交及 View 销毁后可读；有界槽位、明确 Busy 和恢复机制 |
| F07 | 帧图 | 纹理/缓冲及子资源读写声明、依赖检查、裁剪、转换、生命周期、持久导入/导出；非法依赖可诊断 |
| F08 | 点云模块 | 位置/颜色/强度/半径数据；与网格双向遮挡，两相机正确；主调度无点云专用分支 |
| F09 | 观测与呈现 | 校准、采样时间、通道语义；调试图不修改同帧真实颜色；窗口只消费输出 |
| F10 | 安装分发 | 外部项目通过 find_package 和导出 target 构建运行；不依赖原源码/构建目录寻找 shader |

## 后续功能，不作为框架首轮完成条件

| 编号 | 功能 | 开发前须补齐的规格和验证 |
|---|---|---|
| F11 | 镜头畸变 | 模型、系数、映射方向、边界填充；标定图验证；ID 最近点采样 |
| F12 | 曝光/运动模糊 | 曝光区间、轨迹采样、全局/滚动快门；已知速度与模糊长度匹配；TAA 不能代替曝光积分 |
| F13 | 传感器噪声 | RGB/深度模型、单位、随机种子、统计指标；可复现且不修改真值 |
| F14 | 雨雪 | 仿真时间驱动、生命周期、遮挡/深度策略；静止相机下仍更新 |
| F15 | 3D Gaussian | 格式、排序/混合、协方差、透明覆盖、深度语义；不能默认把合成深度标为几何真值 |
| F16 | 真实感升级 | HDRI/IBL、透明等分别立项，给出参考图、质量和性能门槛 |
| F17 | 可选 DLSS | SDK/硬件、运动向量/曝光协议及无 SDK 回退，不成为基础依赖 |

GPU 遮挡剔除已按用户要求移除，不列入计划；保留 CPU 视锥剔除。完整 three.js API、全部 glTF 扩展和多 GPU 不属于当前承诺。
