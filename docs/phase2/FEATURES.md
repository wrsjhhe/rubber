# 第二阶段功能范围

## 本轮必交付

| 编号 | 功能 | 必须交付 | 边界 |
|---|---|---|---|
| S2-F01 | 可组合处理链 | 显式输入引用、只读前序派生数据、输出类型/单位/域/有效性描述、全链预校验 | 首版 CPU；GPU 后端不作为本轮完成条件 |
| F11-A | 镜头畸变 | Brown–Conrady 五系数、目标到源逆映射、RGB/深度/ID 重采样、有效掩码 | 不含鱼眼、色差、暗角、自动补全视野 |
| F12-A | 全局快门 | 多时刻重新渲染、矩形曝光权重、RGB 线性积分、独立参考时刻真值 | 不把 TAA 当曝光，不含滚动快门、自动轨迹推断 |
| F13-A | RGB 噪声 | 在线性传感器域上的独立高斯读出噪声、亮度相关高斯噪声近似、确定性随机数 | 不是实测相机拟合，不宣称完整光电或 ISP 模型 |
| F13-B | 深度噪声 | 米制深度偏差、随深度变化的高斯误差、独立丢点概率、有效掩码 | 不模拟 ToF 多径、结构光匹配、双目遮挡误差 |
| S2-F02 | 集成与验证工具 | 安装包外部离屏传感器示例；资产验证命令行输出颜色/深度/ID 与检查报告 | 不做完整编辑器或 GDS 集成 |

RGB 默认链：多时刻线性渲染 → 曝光平均 → 镜头重映射 → 噪声 → 显示变换。零曝光单帧可直接进入镜头阶段。深度/ID 默认来自参考时刻独立分支：原始真值 → 镜头重映射 → 深度噪声（仅深度）。ID 不加噪声、不积分、不做线性采样。

畸变深度仍表示对应源射线命中的光轴 Z，单位米，不自动转换为射线长度。畸变后的深度/标签称为“派生参考标签”，不覆盖原始几何真值。运动模糊 RGB 不能宣称与单时刻 ID 一一对应。

每份派生输出必须记录源观测/捕获标识、处理链版本、模型参数、单位、像素域、标定、有效性和时间语义。同名不同语义的输出不能静默互换。已有 Color、Resolved、MetricDepth 等枚举保持含义不变。

## 后续立项，非本阶段承诺

| 功能 | 建议入口 | 开工前必须确定 |
|---|---|---|
| F12-B 滚动快门 | 捕获调度器的逐行时间模型 | 扫描方向、行曝光/读出时间、行组误差、运动参考真值 |
| F14 雨雪 | 独立天气渲染模块 | 确定性仿真时钟、粒子寿命、遮挡/透明深度、天气对标签的影响 |
| F15 3D Gaussian | 与 mesh/points 并列模块 | 文件格式、协方差坐标、排序与混合、合成深度命名、规模预算 |
| F16-A HDRI/IBL | 光照资源与 pass | 环境贴图色域、预滤波、参考场景、材质一致性 |
| F16-B 透明材质 | 独立透明路径 | 排序策略、多层覆盖、透明物体的传感器深度定义 |
| F17 DLSS | 可选重建适配器 | SDK/许可/硬件、速度/深度/曝光协议、无 SDK 回退、真值隔离 |
| GPU 传感器处理 | 帧图 compute pass | CPU/GPU 数值误差、GPU 结果保活、导出同步与无读回测试 |

天气和高斯不是 CPU 图像处理阶段；不得为复用处理链而把场景效果伪装成后处理。上述任务只有预留边界，没有完成详细设计。CPU 视锥剔除继续保留，GPU 遮挡剔除不恢复。
