# 第二阶段技术契约

以下是新增路径的实现规格，尚不是现有 API 行为。

## 1. 数据与像素域

内部像素坐标采用左上角原点，像素中心为 (i+0.5,j+0.5)，x 向右、y 向下。标定必须与渲染投影保持同一约定；接入采用整数像素中心的外部标定时显式转换主点，禁止偷偷加半像素。S2-00 用实际投影测试锁定适配规则。

派生描述至少包含 name、format、width/height、单位、domain（线性颜色/显示颜色/光轴深度/离散标签/有效掩码）、标定引用和模型版本。标定包含原始内参、输出内参、畸变模型与系数；不能给畸变图只附一份无畸变内参。

有效掩码独立为 R32Uint（0 无效、1 有效），复用现有像素格式；不得占用 Resolved.a。颜色无效填黑，深度/ID 无效填零，并同时给掩码。相机背景是有效颜色，背景深度零则无几何命中；颜色有效性与几何有效性分别表示。

所有尺寸/stride/总字节数用检查溢出的宽整数计算，非有限参数、负曝光、无效焦距、非法近远平面在提交 GPU 或分配大数组前拒绝。

## 2. F11-A 镜头畸变

首版固定 Brown–Conrady：径向 k1/k2/k3、切向 p1/p2；系数为无量纲。理想归一化坐标 (x,y)，r²=x²+y²：

```text
s = 1 + k1*r² + k2*r⁴ + k3*r⁶
xd = x*s + 2*p1*x*y + p2*(r²+2*x²)
yd = y*s + p1*(r²+2*y²) + 2*p2*x*y
```

这是理想坐标到畸变坐标的正向模型。生成畸变图时，逐目标像素以输出内参求 (xd,yd)，数值求逆得到 (x,y)，再用源内参映射到源图；不能直接拿正向式当反向采样地址。

CPU 用 double 求映射，最多 20 次带阻尼 Newton 迭代，残差换算为输出像素后须 ≤1e-4 像素。非有限值、近奇异 Jacobian、未收敛或源坐标越界均标无效。首版仅支持校验域内单值的模型；建图时在输出中心网格及边界检查局部可逆性，发现折叠/负 Jacobian 拒绝模型。离散检查不是全连续域可逆性证明，极端参数不保证有效。

RGB 在**线性域**双线性采样；支持范围为源中心 [0.5,width-0.5] × [0.5,height-0.5]，边界邻居钳制到边缘中心，范围外不延拓。深度与 ID 使用同一最近像素索引，深度零保持无效，禁止跨前景/背景插值。零系数且内参/尺寸相同走恒等复制，像素与掩码语义保持一致。

不自动扩大 FOV：边缘丢失由掩码表达。缓存键包含模型/版本、全部系数、源与目标内参及尺寸，不含场景内容；参数改变必须重建映射。静态镜头可在线性时间平均后重映射；曝光期间变焦/畸变变化本轮拒绝。

## 3. F12-A 全局快门

保留旧 SampleTime 的起点语义，新的 CaptureSpec 明确 t0、duration=T、referenceTime=t0。T>0 时矩形快门取 N 个中点样本：t_i=t0+(i+0.5)*T/N，权重 1/N。T=0 强制单样本 t0。参考几何单独在 t0 获取，不从时间平均里提取深度或标签。

CaptureSequence 提供每个 t_i 的不可变快照与相机，快照 time 必须等于请求时刻；曝光内允许相机与物体运动，内参/分辨率/镜头参数固定。首版要求实例身份与拓扑固定；不支持的拓扑、资产版本变化需显式报错。应用可提供解析轨迹，不由渲染器从 Motion 反推完整运动。禁止用首尾帧图像混合替代中间重绘。

每个时间样本使用无抖动、无历史复用的瞬时线性光照，首版复用 taa=false 的 Hdr RGB，仅处理 RGB，不把 Hdr.a 的覆盖值作为颜色相乘。累加为 FP32，结果是曝光期间平均线性颜色；不重复叠加已有显示曝光增益。这是相对场景线性值，未经光度学标定，不宣称 W/sr/m²。

这条专属曝光路径是对旧“线性下游统一使用 Resolved”建议的有意细化：普通单帧下游仍可使用 Resolved；曝光不能再混入跨曝光历史，否则会重复积分。现有 Hdr、Resolved 和 Color 不改名、不改语义。

首版无空间超采样，运动模糊不等于抗锯齿；原有 TAA 继续服务显示路径。N 默认 8，可配置 1—64；超过上限拒绝而不是静默截断。N=8 不保证所有速度足够准确，结果须记录 N，验收以收敛测试而非默认值证明精度。

CaptureResult 独立于 Observation：持有 t0 的参考观测，另存曝光区间、精确样本时刻/权重、相机轨迹来源版本、平均颜色和派生链描述。不得把曝光积分结果包装成某个单时刻 FrameResult。深度首版不积分，不宣称模拟深度设备自身的曝光物理。

## 4. F13 基础噪声

RGB 首版选择可解释的归一化近似，输入曝光平均后的线性 RGB。显式参数 gain 将相对渲染值转换到归一化传感器域：s=max(gain*L,0)。独立通道噪声 e 的均值为 0，方差为 a*s+b²；a≥0，b≥0。输出 clamp(s+e,0,1)。a=0 为纯读出噪声；亮度相关高斯项不是低光子的 Poisson 模拟。测试统计使用饱和前值或远离截断的输入。关闭模型为精确旁路，不等同于仅将 a/b 置零后仍执行 gain/clamp。

深度输入 z>0，单位米：z'=z+bias+Normal(0,σ(z)²)，σ(z)=a+b*z²；a 为米，b 为 1/米且均非负，bias 为米。独立概率 p∈[0,1] 置无效；原无效值仍为零；结果非正、非有限或超出有效近远范围时置零并清除掩码。首版不改 ID，派生深度不再标为真值。

随机数按 seed、sensorId、captureIndex、stageStableId、pixelIndex、component、drawIndex 构造，不依赖执行顺序、线程号、墙钟或 View 地址。S2-04 固定算法版本、整数混合及正态转换的 golden 向量。相同平台/构建/版本保证逐字节重现；跨平台浮点变换只承诺统计与容差一致，不声称逐位相同。固定模式噪声、热像素、Bayer/去马赛克和实测标定另立项。

## 5. 执行顺序和显示

RGB：曝光线性平均 → 畸变 → 噪声 → 显示变换。深度：参考真值 → 畸变最近点 → 深度噪声。标签：参考真值 → 畸变最近点。模型关闭时保持旁路；有效性不同的分支不能共用一个含义不明的掩码。

显示阶段复用已有曝光增益、ACES 和 sRGB 约定，另产出派生 RGBA8；本轮 alpha 固定 1，掩码独立。不要对已编码 Color 直接加物理意义的噪声或做曝光积分。执行链顺序写入结果；改变顺序属于新配置版本。
