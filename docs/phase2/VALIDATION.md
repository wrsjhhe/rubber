# 第二阶段验收标准

数值门槛在实现前固定；改变门槛必须说明数学或测量依据，不因测试失败直接放宽。只改文档不要求 GPU 回归。以下均是计划，未运行。

## 正确性测试矩阵

| 测试 | 关键场景 | 通过门槛 |
|---|---|---|
| processing_check | 依赖排序、前序输出只读、异常、循环/缺输入/重名/错单位/溢出 | 非法声明时阶段调用计数为 0；源字节前后相同；输出持有后续运行不污染 |
| lens_check | 零系数、非零径向/切向、主点偏移、fx≠fy、640×360 与 320×480 | 恒等映射逐字节一致；独立正向解析点与逆映射往返误差 ≤0.05 像素；ID 输出只含源标签，无新混合值 |
| lens_check 边界 | 前景/背景边缘、越界、非收敛、极端系数 | 深度/ID 使用同一最近点；无效掩码与填充值匹配；非法模型明确拒绝；不产生未标记 NaN |
| exposure_check 静态 | T=0、N=1、静态 N=8/32、显示历史前后 | T=0 等价无历史瞬时渲染；静态积分 RGB 最大误差 ≤0.002×max(1,参考峰值)；参考深度/ID 逐字节一致 |
| exposure_check 运动 | 固定 Z 的横向匀速物体、相机运动、遮挡出现/消失 | 轮廓扫掠增量与 fx·abs(vx)·T/Z 相差 ≤max(1 像素,5%)；禁止首尾图混合通过；参考真值为 t0 |
| exposure_check 收敛 | 不饱和高对比运动边缘 | 用 N=64 为测试参考，N=32 的平均绝对误差 ≤N=8 的误差且 ≤参考峰值的 2%；固定场景/ROI 写入测试，不要求所有场景误差严格单调 |
| noise_check | 均匀线性色、均匀有效深度、多种强度/距离 | 每点至少 100000 样本；均值误差 ≤5σ/√n；方差相对误差 ≤5%；截断/无效处理另测 |
| noise_check 丢点与随机 | 固定 seed、改变 sensorId、改变执行顺序 | 同平台同版本逐字节重现；调度顺序不影响结果；丢点率误差 ≤5√(p(1-p)/n)+1/n；p=0/1 精确通过 |
| sensor_pipeline_check | 两相机、移动场景、畸变+曝光+噪声、调试切换 | 来源/时间/参数齐全；禁用效果精确旁路；源观测不变；两相机结果及历史不交叉污染 |

禁止用生产实现本身计算唯一期望值：畸变用独立正向解析式和已知点；曝光用解析速度与高采样参考；噪声用理论统计。显示图不用于线性积分误差统计。

## 资源和失败路径

- 固定场景与动态快照分别运行至少 1000 次捕获，交替保留/释放结果，记录 CPU 内存、stagingBytes、pendingUploads、帧槽与映射缓存计数。释放结果并等待 GPU 后暂存归零或回到明确固定基线；缓存只按配置数量有界增长，禁止随捕获次数线性增长。
- 请求超过 maxSamples/maxPixels/maxWorkingBytes 在工作启动前失败；测试宽整数溢出、非法曝光、缺失轨迹时间、不同内参和资产变化。
- 槽满返回 Busy；释放持有结果后可恢复，不能死锁。中途阶段抛错或时间采样失败，不返回半成品、不污染下一次捕获。
- 新 GPU 提交路径运行 validation。缺少 validation 或计数设施时如实记录范围，不把没有控制台输出当成全面内存安全证明。
- 安装后的外部消费者包含新增公开头，仅链接 sim::renderer 即可编译运行；关闭 example 仍可构建；测试的写入清理仍仅在专属目录。

## 性能测量与预算

固定并记录 GPU/驱动/CPU/构建配置、场景资产版本、分辨率、阴影、样本数、输出通道和交付方式。预热 30 次，测量至少 200 次，报告 p50/p95、CPU 处理时间、GPU 渲染时间（有计时查询才报告）、读回字节、峰值内存。没有 GPU 查询时只能称端到端时间。

矩阵：640×480 与 1280×720；1/4 相机；N=1/8/32；镜头关/开；噪声关/开。CPU 首版有读回，不承诺 GPU 零拷贝或硬件无关 FPS。

门槛：旧路径关闭新增功能时，同机重复三轮的端到端 p50/p95 中位数相对 S2-00 基线退化不超过 5%；噪声和镜头 CPU 处理使用有界内存；顺序积分临时图像数量不随 N 线性增长。阈值受系统波动影响时附原始数据并复测，不静默删异常样本。效果开启后的吞吐先报告实测，不凭空规定实时帧率。
